Fonts are part of a theme, and the user can switch them as a secondary setting. All are OFL and bundled through Fontsource, so they show everywhere rather than only where they're installed. Terminals use the terminal's font.

<FontSpecimen />

Also available, not featured: Hubot Sans, Atkinson Hyperlegible Next, Public Sans, Source Sans 3, Figtree, Manrope, Instrument Sans, Onest and Schibsted Grotesk. A theme's style names its font; the generated `--ds-font-sans`, `--ds-font-figures` and `--ds-font-mono` variables carry the stack.

## Scale

| Token | Size |
| --- | --- |
| `--ds-font-size-2xs` | 0.6875rem |
| `--ds-font-size-xs` | 0.75rem |
| `--ds-font-size-s` | 0.875rem |
| `--ds-font-size-m` | 1rem |
| `--ds-font-size-l` | 1.125rem |
| `--ds-font-size-xl` | 1.375rem |
| `--ds-font-size-2xl` | 1.75rem |
| `--ds-font-size-3xl` | 2.125rem |
| `--ds-font-size-4xl` | 2.5rem |

Every size multiplies by `--ds-font-size-multiplier`, so an app can offer a text size setting. Weights come from the theme as `--ds-font-weight-regular` and `--ds-font-weight-strong`.
