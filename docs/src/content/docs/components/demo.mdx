Components are Lit elements on native elements, styled only through `--gw-*` variables. They're copied into each app and owned there, then kept in sync.

Blume's islands don't support Lit, so demos load through an Astro `Demo` component instead. It wraps its content in a Lit frame with a theme and mode picker, and a bundled script registers the elements. Pick a theme or mode and the buttons follow it.

<Demo theme="glazing">
  <gw-button variant="primary">Reboot</gw-button>
  <gw-button variant="accent">Plan boot</gw-button>
  <gw-button>Cancel</gw-button>
  <gw-button variant="danger">Remove backup</gw-button>
  <gw-button disabled>Unavailable</gw-button>
</Demo>

## `gw-button`

| Attribute | Values |
| --- | --- |
| `variant` | `neutral` (default), `primary`, `accent` or `danger` |
| `disabled` | Disables the native button inside |

It renders a native `<button>` in its shadow root, so keyboard use, focus and form behaviour come from the browser. The focus ring uses `--gw-color-focus` and `--gw-focus-width`.
